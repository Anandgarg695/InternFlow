# InternFlow

A complete internship lifecycle platform: Discover → Apply → Screen → Test → Interview → Select → Offer → Onboard → Work → Evaluate → Complete → Certificate.

Roles: Student, Company, Mentor, Admin.

## Tech Stack
- Frontend: React, Vite, React Router, Redux Toolkit, Axios, Tailwind CSS
- Backend: Java, Spring Boot, Spring Security, JWT, Spring Data JPA
- Database: PostgreSQL (via Docker)

## Folder Structure
- `frontend/`: React app
- `backend/`: Spring Boot API
- `docker/`: Docker and infrastructure files
- `docs/`: documentation and progress tracking
